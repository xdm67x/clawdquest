Clawd, the boss
Character: "Clawd" (Claude Code as a desktop pet), from
https://github.com/rullerzhou-afk/clawd-on-desk (AGPL-3.0).

The pixel-art Clawd in js/boss.js is an original hand-drawn voxel
rendition of the character (the Claude spark with a face), inspired by
that project's animated sprites. No files from the repository are
included here; if you redistribute this app, credit the character's
origin project.
